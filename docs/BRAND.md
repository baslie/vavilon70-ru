# Визуальный язык сайта

Ориентир — брендбук формы `docs/photo_2_2026-10-20_14-40-55.jpg`. Главное пожелание заказчика: **минимализм, эстетика и крутость**. Минимализм здесь означает спокойную раскладку брендбука, а не голую страницу: светлое поле, много воздуха, точная сетка, энергия сосредоточена в фото и фирменной графике.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `mist` | `#E7E7EA` | Основной фон, как поле брендбука |
| `ink` | `#0E0E11` | Текст, тёмные плашки, тёмный вариант страницы |
| `paper` | `#FAFAFA` | Текст на тёмном |
| `violet` | `#7D39EB` | Главный акцент бренда: обводка логотипа, кнопки, крупные цифры |
| `signal` | `#FF2B2B` | Короткие тире-маркеры, полоса, мелкие детали. Не для текста на сером: мало контраста |

Лайм (`#C6FF33`) есть во второй версии формы (`photo_5`), но в основной палитре сайта не используется.

## Шрифты

| Роль | Шрифт | Как |
|---|---|---|
| Логотип | Dela Gothic One | Только знак «ВАВИЛОН», стикер с белой и фиолетовой обводкой (`src/components/Logo.astro`). Временный, до вектора от заказчика |
| Заголовки | Unbounded | 800, капс, наклон −8°, плотный интерлиньяж (`.headline`) |
| Подписи | Onest | 12px, капс, разрядка 0.22em (`.label`): «ЭНЕРГИЯ / ДВИЖЕНИЕ / ЛЮДИ» |
| Текст | Onest | 16–18px, обычный регистр |

Все три шрифта с кириллицей, подключены через Fontsource без внешних запросов.

## Графические приёмы

- **Подписи-слоганы.** `ЭНЕРГИЯ / ДВИЖЕНИЕ / ЛЮДИ / ВАВИЛОН`, `JUMP TRAIN PLAY REPEAT`, `ARENA / ХАРАКТЕР / ДВИЖЕНИЕ / КОМАНДА`.
- **Стрелка ↗.** Крупная, чёрная, как в углах брендбука.
- **Тонкие линии** длиной в колонку, разделяют подписи.
- **Полоса из параллелограммов.** Фиолетовый, красный, чёрный, белый.
- **Короткое красное тире** под списком слов.
- **Молнии и полутона** живут только внутри фото и текстур ткани (`src/assets/photos/*texture*`), не рисуются поверх страницы.

## Фото

Временные, сгенерированы через `royal-techno` (см. `docs/SKILLS.md`). Свет: фиолетовый и красный, белый ключевой, без зелёного и жёлтого. После съёмки в зале заменить, сохранив ключи в `src/data/photos.ts`.
