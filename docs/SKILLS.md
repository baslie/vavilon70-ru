# Скиллы проекта

Какие скиллы Claude Code используем на сайте «Вавилона» и когда их вызывать. Порядок таблиц совпадает с порядком работы: от дизайна к публикации.

Скиллы двух видов:
- **проектные** лежат в `.claude/skills/`, закоммичены в репозиторий, источники и хэши записаны в `skills-lock.json`. Обновить: `npx skills update -p`, восстановить на новой машине: `npx skills experimental_install`;
- **глобальные** установлены у Романа в `~/.claude/skills/` или приходят из плагинов (`seo-geo`, `vercel`). В репозитории их нет.

## 1. Дизайн и макеты

| Скилл | Где | Когда вызывать |
|---|---|---|
| `design-taste-frontend` | глобальный | Старт каждого варианта первого экрана: выбрать направление, не скатиться в шаблон, пройти pre-flight чек-лист |
| `frontend-design` | глобальный | Вёрстка hero и блоков: композиция, характер, детали |
| `web-typography` | **проектный** | Выбор шрифтов с кириллицей, пары, шкала размеров, `@font-face` и загрузка |
| `refactoring-ui` | глобальный | Иерархия, отступы, цвет, тени; приведение варианта в порядок после первой сборки |
| `tailwind-design-system` | глобальный | Токены бренда в `@theme` (Tailwind v4), единая шкала |
| `svg-logo-designer` | глобальный | Векторная версия логотипа и графических мотивов (корона, стрелки, штрихи) |
| `royal-techno` | глобальный | Только по запросу: сгенерировать фон или фото-заглушку, если нет реальных фото |

## Добавить новый скилл

1. Поиск: `npx skills find <запрос>`.
2. Установка в проект: `npx skills add <owner/repo> -s <skill> -a claude-code --copy -y`.
3. Просмотреть `SKILL.md` и `references/` перед использованием: скиллы работают с полными правами агента.
4. Дописать строку в нужную таблицу этого файла.
